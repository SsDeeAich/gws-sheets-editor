# Google Workspace Skills for Google Sheets

This repository includes two focused skills for AI agents:

## 1. Custom Business Rules: `customer-spreadsheet-editor`
- **Location**: `skills/customer-spreadsheet-editor/SKILL.md`
- **Purpose**: Defines business rules for reading existing planning spreadsheets, managing the `"Agent Recommendations"` tab, matching records by `recommendation_id`, performing in-place updates vs appends, and executing post-mutation verification.

## 2. CLI Tool Reference: `gws-sheets`
- **Location**: `skills/gws-sheets/SKILL.md`
- **Purpose**: Provides command reference and parameter schemas for interacting with the Google Sheets API via `@googleworkspace/cli` (`gws`).
